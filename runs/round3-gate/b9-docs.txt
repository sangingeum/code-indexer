$ code-indexer find-symbol --help
                                                                                
 Usage: code-indexer find-symbol [OPTIONS] [name]                               
                                                                                
 Look up symbols by name in the manifest symbol index (no semantic search).     
 Exact AST-first, capped substring fallback. With NAME omitted, browse mode:    
 filters only, capped at --limit (design §2.3).                                 
                                                                                
 The structural filters (--kind, --name-pattern, --file, --container,           
 --visibility, --language, --inherits, --has-call) compose as AND in one        
 SQL read. --inherits/--has-call answer from attributed syntax only, so         
 an empty answer there is "not attributed", never "no" — the payload            
 labels every row and names the unattributed files.                             
                                                                                
 --limit keeps its meaning and its default, and a capped answer says it         
 was capped: JSON carries match_count and truncated, text mode prints           
 how many of how many were shown.                                               
                                                                                
 A read: --refresh is the only flag that makes it write, --fresh is inert,      
 and the JSON object carries the staleness block.                               
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│   name      <str>  Symbol name (optional: omit for browse mode with          │
│                    filters).                                                 │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --project,--name                   <str>  Project path, slug, or name        │
│                                           (--project X or --name X).         │
│ --kind,--type,--symbol-type        <str>  function|method|class|struct|enum… │
│ --file                             <str>  Restrict to this file              │
│                                           (project-relative).                │
│ --name-pattern                     <str>  Glob over the name, case-sensitive │
│                                           (`*Manager`, `get_*`).             │
│ --container                        <str>  Parent qualified name (exact),     │
│                                           e.g. `UserManager`.                │
│ --visibility                       <str>  public|private (a NULL visibility  │
│                                           reads as public).                  │
│ --language                         <str>  File language, e.g. python.        │
│ --inherits                         <str>  Base class name from an attributed │
│                                           `base_class` reference.            │
│ --has-call                         <str>  Callee name from an attributed     │
│                                           `call` reference.                  │
│ --substring                               Substring match (browse mode).     │
│ --limit                            <int>  Max rows. Exact-name mode: every   │
│                                           definition unless given. Browse    │
│                                           mode and the substring fallback:   │
│                                           default cap 25.                    │
│ --json                                    JSON output.                       │
│ --skip-stale-check                        Accepted on every command and      │
│                                           INERT: reads never index, so there │
│                                           is nothing to skip. Reporting      │
│                                           staleness without repairing it is  │
│                                           the default; use --refresh to      │
│                                           repair.                            │
│ --refresh                                 Run an incremental index pass      │
│                                           first (one per project for         │
│                                           --all-projects / doctor), then     │
│                                           answer from the result. This is    │
│                                           the ONLY flag that turns a read    │
│                                           command into a write; a pass held  │
│                                           by another process fails with      │
│                                           LockedError (exit 5).              │
│ --fresh                                   Read the live file and ignore      │
│                                           cached symbol rows (this command   │
│                                           only). Writes nothing.             │
│ --help                                    Show this message and exit.        │
